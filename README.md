# Fairy rings

A simple plugin that adds a search bar to the fairy ring interface in RuneScape. You can search both by code, destination and alias (For example, searching "varrock" will find the "D K R" fairy ring in edgeville).

## Archived
This repository has been archived, the fairy rings search functionality has been bundled into the [Better Teleport UIs](https://github.com/WerWolv/RuneScapeBetterTeleportUIs) plugin by WerWolv.
